# use-vm-lease — 動手之前先佔住

同一台電腦上可能有別的工作階段正在用同一批虛擬機。**還原快照會把對方做到
一半的工作抹掉，而且不會有任何錯誤訊息**——事後從症狀看不出成因，只會覺得
「剛才那步好像沒生效」。

## 在你自己的 repo 採用

這份 skill 是可以直接複製走的——把整個資料夾抄進你的 repo 的
`.claude/skills/`，再做兩件事：

```bash
pip install -e D:\Github\vm-lease_專案\vm-lease
```

```powershell
$env:VM_LOCK_OWNER = "你的工作階段代號"     # 建議設成使用者層級的環境變數
```

然後在你的 `CLAUDE.md` 裡加一行，指名「碰虛擬機之前先走這個 skill」。

**不另外做一支產生器來自動建立這份 skill。** 那會多出一條要維護的路：用法
一改，除了改這份文件還要改產生器，而產生器平常沒有人跑、壞掉也不會有人發現。
直接複製看起來原始，但它只有一份東西要同步。

## 每次用之前先看一眼說明書

```bash
cat docs/使用說明書.md
```

這個工具的行為調整過不只一次（尤其**租期的意義**與**失去租約時該做什麼**），
照印象使用容易踩到已經改掉的舊做法。花十秒看一遍。

## 先給自己一個名字

```powershell
$env:VM_LOCK_OWNER = "你的工作階段代號"
```

不設會直接失敗，訊息會告訴你要設什麼。不接受匿名——匿名等於誰都可以續別人
的租約。

## 第一次用：先登記虛擬機

這個工具同時保管「這台電腦上有哪些虛擬機」。清單不存在時，占用會直接失敗並
告訴你要下什麼指令。

```bash
vm-lease machines list                      # 看有哪些
vm-lease machines show win11                # 看一台的完整內容
vm-lease machines add <代號> --vmx <路徑> \
  --snapshot <快照> --user <帳號> --password-env <環境變數名>
```

**清單不存密碼**，只存密碼放在哪個環境變數——命令列沒有任何選項可以把密碼
寫進去。快照與登入帳號要一起給，因為兩者是成對的。

## 標準用法：一支程式做完就還

```python
import vm_lease

with vm_lease.reserved("win11", purpose="驗證註冊行為"):
    ...        # 這段期間別人拿不到這台機器
# 離開區塊自動還，中途拋例外也會還
```

**大部分情況用這個。** `purpose` 會寫進租約——別人被擋下來時看得到你為什麼
在用，比只看到一個代號有用得多。

## 跨好幾支程式時

一件事分成好幾支程式做（先布置環境、交給人操作、再回來量結果）時，程式結束
了但工作還沒完，要自己講：

```python
lease = vm_lease.acquire("win11", purpose="驗證註冊行為")
# 記下 lease.token 給下一支程式

vm_lease.renew("win11", token=lease.token)   # 每次碰它之前
vm_lease.release("win11")                    # 全部做完
```

## 租期的意思跟你想的不一樣

**「5 分鐘」不是「你只能用 5 分鐘」，是「你 5 分鐘沒碰它才算你走了」。**

每碰一次虛擬機，時間就自動往後推。透過 `tools/vms.py` 這類驅動模組操作時
那邊已經接好，不用自己呼叫。

**唯一的例外是把畫面交給人手動操作**——那段期間沒有任何操作發生，自動延長
不會觸發，要自己借久一點：

```python
vm_lease.acquire("win11", purpose="等使用者手動操作", minutes=30)
```

## 兩種錯誤，處置完全不同

| 遇到 | 意思 | 怎麼辦 |
|---|---|---|
| `VmBusy` | 機器被別人佔著 | **不要自己搶。** 把訊息（含持有者、用途、到期時間）原樣轉給使用者，要不要搶是他的決定 |
| `LeaseLost` | 你手上那張已經不是你的了 | **立刻停止操作那台機器。** 另一邊可能正在上面工作 |

`LeaseLost` 通常代表有人強制拆過鎖。這個提醒本身就是設計的一部分——沒有它
你會安靜地把機器再佔回來，然後兩邊都以為自己拿著。

## 在命令列查看

```bash
vm-lease who win11        # 現在誰佔著
vm-lease log --lines 30   # 最近發生過什麼
```

**一輪測試如果拿到看起來合理、但其實不對的結果，先來看 log**：查那段時間
機器有沒有換過手。這正是當初做這個工具的起因。

結束碼：`0` 成功、`2` 用法錯誤、`3` 被別人佔著、`4` 租約已經不是你的。

## 想強制放掉一台機器

```bash
vm-lease release win11 --force
```

或直接刪掉租約檔（錯誤訊息裡有路徑）。**這是使用者的決定，不是 agent 的**
——原持有者可能正在做一件跑到一半就毀掉很可惜的事。

## 已知限制

- 跨程式那種借法忘記還的話，機器會被佔到租期結束，沒有自動解法。
- 作業系統層級的臨界區目前只有 Windows 用真正的互斥鎖。
