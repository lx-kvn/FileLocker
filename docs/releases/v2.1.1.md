# FileLocker v2.1.1

## 繁體中文

修正自動更新會誤裝成 CLI 版安裝檔、GUI 本體實際沒被更新的問題，並縮小 GUI 安裝檔大小、修正執行檔版本號一直停在 1.0.0.0。

### 亮點

- **修正自動更新選錯安裝檔**：v2.1.0 這輪同一次發布新增了 CLI 獨立發布產物之後，App 內建的「檢查更新」功能選下載目標時，原本邏輯是「抓 GitHub Release 附件清單裡第一個副檔名是 `.exe` 的」——GitHub 是照檔名字母排序顯示附件（`FileLocker_CLI_...` 的 `C` 排在 `FileLocker_v...` 的 `v` 前面），導致選到 CLI 版安裝檔、靜默裝到完全不同的資料夾，GUI 本體從頭到尾沒被更新，卻回報「更新成功」。新增 `SelfUpdateAssetSelector` 明確排除 CLI 版安裝檔，不再依賴附件排序。
  - **如果你是從 v2.1.0（或更早版本）手動更新到這一版，建議直接從 [Releases 頁面](https://github.com/lx-kvn/FileLocker/releases) 下載安裝，不要用 App 內建的「檢查更新」**——舊版本身帶的就是有問題的那套選檔邏輯，沒辦法用它自己更新自己。這一版起「檢查更新」才會恢復正常。
- **GUI 安裝檔瘦身**：GUI 跟內建的 CLI 是同一次建置產出，過去安裝檔裡的 `cli/` 子資料夾整份重複帶一份跟外層一模一樣的共用套件（約 57MB），現在只保留 CLI 自己的檔案（約 300KB），安裝檔整體從約 106MB 降到約 82MB。獨立發布的 `CLI_setup`／`CLI_zip` 不受影響，維持自帶完整套件。
- **修正執行檔版本號停在 1.0.0.0**：`FileLocker.exe`／`FileLocker.Cli.exe`／`FileLocker.UpdateRelauncher.exe` 在檔案總管「內容」→「詳細資料」看到的版本號，過去因為建置指令沒有帶版本號進去，一直顯示 .NET SDK 預設值 `1.0.0.0`，現在會正確顯示實際發布的版本號。

### 已知限制

（跟 v2.1.0 相同，這輪未變動，見該版 Release Notes。）

## English

Fixed the auto-update feature silently installing the CLI-only build instead of updating the GUI app itself, and shrunk the GUI installer's size, and fixed executable file version numbers stuck at 1.0.0.0.

### Highlights

- **Fixed auto-update picking the wrong installer**: after v2.1.0 added the standalone CLI distribution to the same release, the app's built-in "check for updates" feature picked its download target by scanning the GitHub Release's asset list for the first name ending in `.exe`. GitHub lists assets in alphabetical order (`FileLocker_CLI_...`'s `C` sorts before `FileLocker_v...`'s `v`), so it picked the CLI installer, silently installed it into a completely different folder, and the GUI app itself was never actually updated — yet reported "update succeeded." Added `SelfUpdateAssetSelector`, which explicitly excludes the CLI installer instead of relying on asset ordering.
  - **If you're updating manually from v2.1.0 (or earlier) to this version, please download it directly from the [Releases page](https://github.com/lx-kvn/FileLocker/releases) instead of using the in-app "check for updates"** — older versions ship with the buggy selection logic, so they can't reliably update themselves. "Check for updates" works correctly again starting with this version.
- **Smaller GUI installer**: the GUI build and its bundled CLI come from the same build, and the installer's embedded `cli/` folder used to duplicate a shared dependency set (~57MB) that's already present one level up. It now keeps only the CLI's own files (~300KB), shrinking the overall installer from about 106MB to about 82MB. The standalone `CLI_setup`/`CLI_zip` distributions are unaffected and still ship the full dependency set.
- **Fixed executable file version numbers stuck at 1.0.0.0**: `FileLocker.exe`/`FileLocker.Cli.exe`/`FileLocker.UpdateRelauncher.exe`'s file version (visible via Explorer's "Properties" → "Details") used to always show the .NET SDK's default `1.0.0.0` because the build commands never passed a version number through. It now correctly shows the actual released version.
